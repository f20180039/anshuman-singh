## 🔧 If Something Goes Wrong

### Issue: Page doesn't load
**Solution**: Make sure dev server is running
```bash
npm run dev
```

### Issue: 3D scene is black/empty
**Solution**: 
1. Check browser console for errors
2. Ensure WebGL is enabled in your browser
3. Update your GPU drivers

### Issue: Performance is slow
**Solution**:
1. Close other browser tabs
2. Enable hardware acceleration
3. Try in Chrome for best performance

### Issue: Mouse controls don't work
**Solution**:
1. Click inside the 3D canvas area first
2. Try a different browser
3. Check if JavaScript is enabled

## 📸 What to Look For

### Animations
- Shapes should be **rotating** continuously
- Shapes should be **floating** up and down slightly
- Central sphere should have **wavy distortion**
- Particles should be **slowly rotating**
- Auto-rotation should be **turning the scene**

### Materials
- Shapes should look **metallic/shiny**
- Shapes should have a **slight glow**
- Colors should be **vibrant**
- Lighting should create **highlights and shadows**

### Performance
- Should run at **~60 FPS**
- Mouse movement should be **smooth**
- No lag or stuttering
