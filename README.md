# My Portfolio

Modern portfolio website with automated resume sync and AI-powered chat assistant.

## Features

- 🎨 Modern design with dark theme and animations
- 📄 **Resume Preview** - In-browser PDF viewer
- 🔄 **Auto-Sync Resume** - Automatically syncs from latex-resume-builder repo
- 🤖 **AI Chat Assistant** - 24/7 recruiter support powered by Google Gemini
- 📱 Responsive design
- ⚡ Fast performance with Vite

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Google Gemini AI
- Express.js backend

## Getting Started

See [ACTION_ITEMS.md](ACTION_ITEMS.md) for complete setup and deployment instructions.
