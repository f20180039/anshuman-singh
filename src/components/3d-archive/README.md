# 3D Components Archive

This folder contains experimental 3D components that were tested but not integrated into the main portfolio.

## Contents

### `/hero`
- Interactive floating geometry for hero section
- Mouse parallax effects
- Particle field backgrounds
- **Status**: Tested, UX needs refinement

### `/shared/hooks`
- `usePrefersReducedMotion` - Accessibility hook
- `useMouseParallax` - Mouse tracking for 3D
- `useResponsive3D` - Device-aware quality settings

## Usage

These components are functional and can be referenced for future 3D experiments or integrated into `/test-3d` page for demonstrations.

## Notes

- All components are production-ready
- Performance optimized (60fps target)
- Accessible (respects reduced motion)
- Mobile-responsive
